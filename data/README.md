## 범위
- 기간: 2026-07-09 ~ 2026-10-16 (100일). 기준일(마지막 날짜)은 2026-10-16
- 날짜 분포: 전날(10-16) 6건 · 최근 7일 17건 · 최근 30일 37건
- 출처 78곳 · 논문 23건(arXiv, Zenodo, ACM, 학술지 등 OpenAlex 오픈 액세스)
- 기획안 v3 주제 5개를 골고루 넣고, 어느 주제에도 안 걸릴 기사(배터리·Rust·Go·천문 등)를 몇 건 섞음
- 주제는 **고를 때만** 참고한 것이고 CSV에는 없다. 실제 분류는 `rules.js`가 한다

## 시험용 줄
| 줄 번호 | 내용 | 기대 동작 |
|---|---|---|
| 40 | 빈 줄 | 건너뛰고 줄 번호 알림 |
| 80 | 날짜 칸이 빈 줄 (`example.com`) | 건너뛰고 줄 번호 알림 |

줄 번호는 머리글을 1로 센 값이다.

## CSV 형식 주의
- 제목에 쉼표가 있는 41줄은 제목을 큰따옴표로 감쌌다 (RFC 4180). `import.js`는 따옴표 안의 쉼표를 칸 구분으로 보면 안 된다
- 제목 안에 큰따옴표가 든 기사는 처음부터 뺐다
- UTF-8, 줄바꿈 LF

## 어떻게 모았나 (2026-10-17)
| 출처 | 쓴 것 | 비고 |
|---|---|---|
| OpenAlex API | 오픈 액세스 논문 (`is_oa:true`) | DOI 링크는 실제 출판사 주소로 바꿈 |
| Hacker News Algolia API | 점수 40 이상 영어 글의 원문 링크 | |
| Google News RSS (한국어) | 기사 목록 | 링크를 실제 언론사 주소로 풀어서 씀. 풀지 못한 것은 뺌 |
| 언론사 RSS | AI타임스 · 전자신문 · 연합뉴스 · 로봇신문 | 최근 날짜 보강 |

저장한 것은 날짜·제목·링크·출처뿐이다. 기사 본문은 저장하지 않았다. 개인 이름은 기사 제목에 나온 공인(기관장·기업인 등)뿐이고, 개인정보는 없다.
